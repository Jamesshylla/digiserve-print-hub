======================================

Create a professional payment page.

Display my Google Pay / UPI QR Code using the uploaded image.

https://i.ibb.co/cXV8YsVx/2e72324e-ee7a-489a-8c9b-c11b710e92b3.jpg

Requirements:

• Show a large QR Code on the payment page.

• Add a "Scan & Pay" heading.

• Add a "Pay Securely via UPI" subtitle.

• Display the QR with rounded corners and a premium card layout.

• After scanning, customers complete payment using Google Pay, PhonePe, Paytm, BHIM, or any UPI app.

• Show a "Payment Complete?" button after payment.

• Generate an Order ID after payment confirmation.

• Save the payment details with the order.

• Generate a downloadable PDF invoice.

• Notify the admin of the new order.

• Send the customer an order confirmation.

• Display payment status:

  - Pending

  - Paid

  - Failed

• Prepare the architecture for future Razorpay/Cashfree integration.
